# OrangeHRM Web Application Testing.

## 📌 Project Overview

This is a practical software testing project based on the OrangeHRM Open Source Demo application.

The project focuses on manual testing, test case design, test execution, validation, and documentation of actual test results with screenshots.

🚧 **Project Status: Testing in Progress**

## 🎯 Objectives

- Practice real-world manual testing
- Design and execute test cases
- Perform positive and negative testing
- Validate application functionality
- Document expected and actual results
- Maintain screenshots as test evidence
- Identify and document issues found during testing

- ## 🧪 Modules Tested

### 🔐 Login Module
